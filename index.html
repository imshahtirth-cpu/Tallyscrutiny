Setup · about 5 minutes

Installation, start to finish

Three separate installs, none of which depend on each other. Load the file into Tally, add the ribbon to Excel, and set the export configuration once per machine. Every step below has a video alongside it.

Loading the file into TallyPrime

Works the same for a .tdl or a compiled .tcp. Five minutes, and the menu appears at Gateway of Tally.

  1. Save the file somewhere permanentPut it in a folder you won't move or rename — C:\TallyScrutiny\ works well. Tally reads this path every time it starts, so a moved file means a missing menu.
  2. Open the TDL screenFrom Gateway of Tally press F1 (Help), then choose TDL & Add-On.
  3. Manage local TDLsPress F4 for Manage Local TDLs, then set Load TDL files on startup to Yes.
  4. Point Tally at the fileUnder List of TDL Files to Preload, type the full path to the file you saved in step 1, including the extension. Accept to save.
    Red syntax error? The file was almost certainly copied incompletely, or the path has a typo. Re-copy the whole file and check the path character by character.
  5. ReloadRestart TallyPrime, or press Ctrl+Alt+R to reload TDLs without closing the company.
  6. Check it loadedBack at Gateway of Tally you'll see TALLY SCRUTINY BY KTS & CO. at the bottom of the menu. Press U to open it.
    Trial licence: enter trial as the key and run your first report in the same session.

Adding the ribbon to Excel

The add-in is a macro file, so Windows and Excel will both try to block it the first time. These two steps get past that for good.

  1. Unblock the file firstRight-click the .xlam file, choose Properties, and if there's an Unblock tick box at the bottom, tick it and click OK.
    Don't skip this. Without it Windows silently disables every macro in the add-in — the ribbon appears but no button does anything.
  2. Open add-in settingsIn Excel go to File → Options → Add-ins. At the bottom set Manage: Excel Add-ins and click Go…
  3. Browse and enableClick Browse, select the .xlam, click OK, then tick its box in the list and OK again.
  4. Allow the macrosIf a yellow security bar appears at the top of the sheet, click Enable Content. Every tool on the ribbon runs on VBA.
    Permanent fix: File → Options → Trust Center → Trust Center Settings → Trusted Locations, then add the folder the add-in sits in. You'll never see the prompt again.
  5. Find the tabA Tally Utilities tab appears on the ribbon, with all twenty-one report tools grouped across it.
  6. ActivateClick Activate and enter your licence key, or trial during the trial period. License Info shows status any time.

Configuring bulk export

Tally can't export several reports in one go on its own. Export All to Excel works around it — but only once three settings are right. This is a one-time setup per machine.

  1. Open the export screenFrom Gateway of Tally press Alt+E, then open Configuration. These defaults apply to every report exported afterwards.
  2. Set a default export folderEvery report in a batch lands here. Use a dedicated empty folder per client per year — D:\Audit\Client\FY25-26\ — because one run can produce twenty-plus files.
  3. Turn "Open file after export" to NoLeave it on and Tally launches Excel after every single report. Twenty reports means twenty windows fighting for focus, and the batch stalls partway.
    This is the one people miss. It's the single most common reason a bulk export dies halfway through.
  4. Turn "Update in existing file" to YesThis lets Tally write into the existing file rather than erroring or spawning clashing duplicates, so repeat runs behave predictably.
  5. Accept and saveConfirm so the configuration persists. Steps 1–5 are needed only once on each machine.
  6. Run the batchOpen Export All to Excel, tick the reports you want before any data loads, and let it run unattended. Then open each file and click Clean Tally Data.
