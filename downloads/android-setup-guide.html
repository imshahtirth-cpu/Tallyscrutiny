1

Windows settings

Turn on Developer Mode

Lets Flutter install the add-on packages it needs.

  1. Click the Start button (Windows logo) at the bottom of the screen.
  2. Type Developer settings. Do not press anything else.
  3. Click Developer settings in the results (or press Enter). Settings opens.
  4. Find Developer Mode and click the toggle on its right so it turns On.
  5. If Windows asks “Turn on Developer Mode?”, click Yes.
  6. Wait a few seconds, then close Settings.
Settings › System › For developers– □ ×
Developer Mode
Install apps from any source, including loose files.
You should seeThe Developer Mode toggle shows On.
2

Version control

Install Git

Git is needed to download Flutter.

2ADownload

  1. Open your web browser (Chrome or Edge).
  2. Click the address bar, type git-scm.com/download/win and press Enter.
  3. 64-bit Git for Windows Setup starts downloading by itself. If not, click that link.
  4. Open the file named like Git-2.xx.x-64-bit.exe from Downloads.

2BInstall 1–2 min

  1. “Allow this app to make changes?” Click Yes.
  2. Licence screen: click Next.
  3. Keep clicking Next on every screen without changing any option: location, components, Start Menu, editor, branch name, PATH, SSH, line endings, terminal and so on.
  4. On the screen with the Install button, click Install.
  5. Click Finish. You may untick “View Release Notes”.
You should seeThe installer closes. Git is installed. You will check it in Step 3.
3

Flutter SDK

Install Flutter

Flutter builds the app. You download it with Git, then tell Windows where it is.

3ADownload Flutter using PowerShell 3–10 min

  1. Click Start, type PowerShell, and click Windows PowerShell. A blue or black window opens.
  2. Create a folder called src on drive C:.
  3. Move into that folder.
  4. Download Flutter. You will see “Cloning into flutter...” and “Receiving objects: 45%”. Do not close the window.

Command for item 2

mkdir C:\src

Command for item 3

cd C:\src

Command for item 4

git clone https://github.com/flutter/flutter.git -b stable
You should seeThe window shows PS C:\src> again and you can type a new command. A folder C:\src\flutter now exists.
If something goes wrong“git is not recognized”: Git was not installed properly or PowerShell was open during the install. Close PowerShell, open it again and retry. Still failing? Repeat Step 2.

3BTell Windows where Flutter is (PATH)

This lets you type flutter in any folder. Beginners most often click the wrong button here, so go slowly.
  1. Click Start and type environment variables.
  2. Click Edit the system environment variables. System Properties opens.
  3. At the bottom right, click Environment Variables...
  4. In the top box, “User variables for (your name)”, click once on Path so it turns blue.
  5. Click Edit... below that top box. Do not click “New...” here.
  6. In the list window, click New on the right.
  7. On the blank line, type exactly C:\src\flutter\bin and press Enter.
  8. Click OK on this window, then OK on Environment Variables, then OK on System Properties.

If something goes wrongA small box called “New User Variable” with the OK button greyed out means you clicked the wrong New... button. Click Cancel, then start again from “click once on the row named Path”.

3CCheck that Flutter works first run 3–5 min

  1. Close PowerShell completely (click the X). The PATH change only works in a newly opened window.
  2. Click Start, type PowerShell, and open Windows PowerShell again.
  3. Run the command. The first run downloads more files, so be patient.
flutter --version
PS C:\> flutter --version
Flutter 3.xx.x • channel stable
Framework • revision ...
Engine • revision ...
Tools • Dart 3.xx.x
You should seeLines such as “Flutter 3.xx.x”, “Framework” and “Dart 3.xx.x”. Any version number means success.
If something goes wrong“flutter is not recognized” means the PATH step (3B) was not saved. Repeat 3B, then close and reopen PowerShell.
4

Android tools

Install Android Studio

Provides the Android SDK and NDK that Flutter builds with.

4ADownload and install about 1 GB

  1. Go to developer.android.com/studio.
  2. Click the green Download Android Studio button.
  3. Tick the box agreeing to the terms, then click Download Android Studio again.
  4. Double-click android-studio-...-windows.exe. Click Yes if asked.
  5. Welcome: Next. Choose components: leave all ticked, Next.
  6. Install location: Next. Start Menu folder: Install.
  7. When finished, Next. Leave “Start Android Studio” ticked and click Finish.

4BFirst-time setup wizard 10–20 min

  1. Asked about importing settings? Choose Do not import settings, OK.
  2. Welcome screen: Next.
  3. Choose Standard, Next.
  4. Pick any colour theme, Next. Verify settings: Next.
  5. Licence screen: click each item on the left (for example android-sdk-license) and click Accept for each.
  6. When all are accepted, click Finish. Wait for downloads, then Finish again.
You should seeThe Android Studio Welcome screen with New Project and Open.

4CInstall the extra tools Flutter needs

  1. On the Welcome screen click More Actions (three dots), then SDK Manager.
  2. Click the SDK Tools tab.
  3. Bottom right: tick Show Package Details.
  4. Tick Android SDK Command-line Tools (latest).
  5. Expand NDK (Side by side) and tick one version (the newest is fine). Write the number down.
  6. Apply, OK, Accept if a licence appears, Next.
  7. When it says Finished: Finish, OK, then close Android Studio.

4DCheck which NDK version was installed

Open PowerShell and run this, replacing <your-username> with your Windows username.

dir C:\Users\<your-username>\AppData\Local\Android\sdk\ndk
You should seeA folder name such as 30.0.16248370. Write this number down. You may need it later.
TipNot sure of your username? Open File Explorer, click This PC, then Local Disk (C:), then Users. Your username is the folder with your name.

4EOnly if the first build says “NDK not found”

  1. Open your project folder in PowerShell, for example cd C:\src\projects\myapp.
  2. Open the build file in Notepad with the first command.
  3. Find the ndkVersion line near the top, inside the “android” section.
  4. Select it and replace it with the exact folder name from 4D, in quotation marks.
  5. Press Ctrl + S to save, then close Notepad.

Open the file

notepad android\app\build.gradle.kts

Find this line

ndkVersion = flutter.ndkVersion

Replace it with (your own number)

ndkVersion = "30.0.16248370"

JavaScript runtime

Install Node.js

Needed to install the Firebase tools in Step 6.

  1. Go to nodejs.org and click LTS (Recommended For Most Users).
  2. Double-click the downloaded .msi file in Downloads.
  3. Welcome: Next. Tick I accept the terms in the License Agreement, Next.
  4. Destination folder: Next. Custom setup: Next.
  5. “Tools for Native Modules”: leave the box unticked, Next.
  6. Install. Click Yes if Windows asks. Then Finish.
  7. Close PowerShell if it is open, and open it again.

Check it

node --version
You should seeA number like v22.x.x.
6

Command-line tools

Install the Firebase and FlutterFire tools

Firebase CLI logs you in to Firebase. FlutterFire CLI connects the app to Firebase.

Run each command in a freshly opened PowerShell window. Wait for the first one to finish before typing the next.

1 · Firebase CLI 1–3 min

npm install -g firebase-tools

2 · FlutterFire CLI, when the prompt appears again

dart pub global activate flutterfire_cli

Lines starting with “Resolving dependencies” and “Downloading” are normal. A yellow warning about PATH at the end is fixed next.

PATHAdd the FlutterFire folder

  1. Click Start, type environment variables, click Edit the system environment variables.
  2. Click Environment Variables...
  3. Top box: click once on Path, then Edit...
  4. Click New and type exactly %LOCALAPPDATA%\Pub\Cache\bin
  5. Press Enter, then OK on all three windows.
  6. Close PowerShell and open it again.

LOGINLog in to Firebase

  1. In PowerShell run firebase login.
  2. Asked about collecting usage information? Type n and press Enter (or y, your choice).
  3. Your browser opens. Click your Google account, or sign in.
  4. Click Continue or Allow on each screen.
  5. At “Firebase CLI Login Successful”, close the tab and go back to PowerShell.
firebase login
PS C:\> firebase login
? Allow Firebase to collect usage information? n
Waiting for authentication...
✔ Success! Logged in as your-email@gmail.com
You should see“Success! Logged in as your-email@gmail.com”.
7

Firebase console

Create a Firebase project

The online database and login your app will use.

7ACreate the project about 30 s

  1. Go to console.firebase.google.com and sign in with your Google account.
  2. Click Create a project (or Add project).
  3. Type a name, for example my-first-app, and click Continue.
  4. If it shows an AI assistance option, leave it as it is and click Continue.
  5. Turn the Google Analytics switch OFF, then click Create project.
  6. When you see “Your new project is ready”, click Continue.

7BTurn on login (Authentication)

  1. Left menu: Build, then Authentication.
  2. Click Get started.
  3. Under “Sign-in method” click Email/Password.
  4. Switch the first Enable toggle on. Leave “Email link” off.
  5. Click Save.

7CCreate the database (Firestore) about 1 min

  1. Left menu: Build, then Firestore Database.
  2. Click Create database.
  3. If asked for an edition, choose Standard, then Next.
  4. Choose the closest location. For India: asia-south1 (Mumbai). This cannot be changed later. Next.
  5. Choose Start in production mode and click Create.
  6. Wait until the empty database screen appears.
